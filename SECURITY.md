# Security Policy

## Supported Versions

Only the latest release of GDrive Manager receives security patches and vulnerability updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

Please report potential security vulnerabilities privately:
- Do **not** disclose security vulnerabilities via public GitHub issues.
- Please submit a private advisory through [GitHub Security Advisories](https://github.com/mohitbhatt-du/gdrive-manager/security/advisories) or email security concerns with reproduction steps to `security@gdrivemanager.local`.

For more details on our threat model and credential vaulting, see [docs/security.md](docs/security.md).
